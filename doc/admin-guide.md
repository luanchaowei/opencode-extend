# 运维指南

本文档面向管理员，介绍统计面板和系统配置的使用方法。

## 统计面板

### 访问方式

在浏览器中访问：

```
http://<WEB_HOST>:<WEB_PORT>/admin.html?token=<VITE_STATS_ADMIN_TOKEN>
```

- `WEB_HOST`：前端监听地址（`.env` 中 `WEB_HOST`）
- `WEB_PORT`：前端端口（`.env` 中 `WEB_PORT`，默认 3000）
- `VITE_STATS_ADMIN_TOKEN`：管理面板访问令牌（`.env` 中配置）

### 概览数据

统计面板顶部显示以下概览信息：

| 指标 | 说明 |
|------|------|
| 累计用户数 | 从数据库统计的不同客户端 IP 数量 |
| 在线用户数 | 10 分钟内有心跳的客户端数量 |
| 累计会话数 | 历史创建的会话总数 |
| 当前会话数 | 当前存在的会话数量 |
| 处理中会话数 | 状态为"AI处理中"或"重试中"的会话数量 |
| 累计消息数 | 历史发送的消息总数 |

### 在线会话表格

显示当前在线的会话列表：

| 字段 | 说明 |
|------|------|
| 会话 ID | Session 唯一标识 |
| 客户端 IP | 客户端 IP 地址（`.` 替换为 `_`） |
| 最后心跳时间 | 最后一次心跳的时间 |
| 状态 | AI处理中 / 重试中 / 空闲 |

- **状态排序**：AI处理中 > 重试中 > 空闲
- **状态筛选**：全部 / AI处理中 / 重试中 / 空闲
- **分页**：每页 10 条

### 使用趋势

显示使用趋势图表，支持 4 种时间范围切换：

| 按钮 | 时间范围 | 聚合粒度 |
|------|---------|---------|
| 近7天 | 7 天 | 按天 |
| 近1月 | 30 天 | 按天 |
| 近1季 | 90 天 | 按周 |
| 近1年 | 365 天 | 按月 |

图表展示以下指标：

- 活跃用户数
- 活跃会话数
- 新建会话数
- 消息发送数

### 刷新方式

- **手动刷新**：右上角"手动刷新"按钮
- **自动刷新**：每 30 秒自动刷新一次

## 系统配置

### 访问方式

在统计面板中点击"系统设置"标签页。

### 配置项说明

| 配置项 | .env 变量名 | 说明 |
|--------|------------|------|
| 支撑人员 | `VITE_CONTACT_ADMIN` | 联系方式列表，多个用 `\|` 分隔 |
| 问题反馈 URL | `VITE_FEEDBACK_URL` | 点击后新窗口打开的反馈页面地址 |
| 知识库目录 | `VITE_CASE_LIBRARY_DIR` | 本地案例库文件所在目录路径 |
| 帮助文档 URL | `VITE_HELP_DOC_URL` | 点击后新窗口打开的帮助文档地址 |
| 公告文案 | `VITE_ANNOUNCEMENT_TEXT` | 顶部公告条显示的内容 |
| 下载截断标记 | `VITE_DOWNLOAD_CUTOFF_TEXT` | 下载回复时从包含此文本的行起截断，为空表示不截断 |

### 注意事项

- 修改配置后建议刷新前端页面确保生效
- 下载截断标记为空时下载完整回复，非空时从包含该标记文本的行起截断
- 支撑人员多个联系方式用 `|` 分隔
- 公告文案支持多行文本
