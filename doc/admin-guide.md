# 运维指南

本文档面向管理员，介绍登录认证、统计面板、系统监控、系统设置和用户管理的使用方法。

## 登录认证

### 启用方式

在 `.env` 中设置 `AUTH_ENABLED=true` 启用登录认证（默认关闭）。启用后，所有用户必须登录才能访问系统。

> **目录命名与隔离**：`AUTH_ENABLED=true` 时，用户目录按 `username` 命名（如 `/home/user/zhangsan`），不同机器登录同一账号可看到相同的历史会话。所有后端请求通过前端服务代理转发，普通用户只能访问自己目录。

### 角色体系

| 角色 | 说明 | 可访问范围 |
|------|------|-----------|
| 超级管理员（super_admin） | 通过 `ADMIN_USERNAME`/`ADMIN_PASSWORD` 配置 | 全部功能，包括用户管理 |
| 管理员（admin） | 由超级管理员创建 | 统计面板、系统监控、系统设置 |
| 普通用户（user） | 由超级管理员创建或通过注册页面自助注册，目录按 username 隔离，只能访问自己目录下的会话 | 仅前端聊天界面，不可访问管理面板 |

### 登录页面

启用认证后，访问系统会自动跳转到登录页 `/login`。输入用户名和密码登录后，会话有效期为 30 分钟，期间操作会自动续期。若管理员开启了自助注册功能，登录页会显示注册入口。

### 用户菜单

登录后，页面右上角显示当前用户名，点击可展开下拉菜单：

- 角色标签：显示当前用户角色
- 管理面板：仅管理员和超级管理员可见，点击在新窗口打开管理面板
- 退出：登出当前会话

## 统计面板

### 访问方式

在浏览器中访问：

```
http://<WEB_HOST>:<WEB_PORT>/admin.html
```

- `WEB_HOST`：前端监听地址（`.env` 中 `WEB_HOST`）
- `WEB_PORT`：前端端口（`.env` 中 `WEB_PORT`，默认 3000）

启用登录认证时，需以管理员或超级管理员身份登录后才能访问。普通用户访问会被重定向到首页。

### 概览数据

统计面板顶部显示以下概览信息：

| 指标           | 说明 |
|----------------|------|
| 总人数         | 累计使用过的不同用户数 |
| 在线人数       | 最近 10 分钟内有活跃的用户数 |
| 总会话         | 历史创建的会话总数 |
| 在线会话       | 最近 10 分钟内有活跃的会话数 |
| 正在处理问题数 | AI 正在处理的会话数 |
| 总消息数       | 用户发送的消息总数 |

### 在线会话表格

显示当前在线的会话列表：

| 字段 | 说明 |
|------|------|
| 会话 ID | Session 唯一标识 |
| 客户端 IP | 客户端 IP 地址（`.` 替换为 `_`） |
| 最后心跳时间 | 最后一次心跳的时间 |
| 状态 | AI处理中 / 重试中 / 空闲 |
| 操作 | 点击"跳转"在新窗口打开对应会话 |

- **状态排序**：AI处理中 > 重试中 > 空闲
- **状态筛选**：全部 / AI处理中 / 重试中 / 空闲
- **IP 筛选**：可按客户端 IP 筛选
- **搜索**：支持按会话 ID、客户端 IP、心跳时间搜索
- **分页**：每页 10 条

### 使用趋势

显示使用趋势图表，支持 5 种时间范围切换：

| 按钮 | 时间范围 | 聚合粒度 |
|------|---------|---------|
| 近7天 | 7 天 | 按天 |
| 近1月 | 30 天 | 按天 |
| 近1季 | 90 天 | 按周 |
| 近1年 | 365 天 | 按月 |
| 自定义 | 自选起止日期 | 按天 / 按周 / 按月 |

点击"自定义"按钮会展开日期选择面板，可设置开始日期、结束日期和聚合粒度（按天/按周/按月），点击"查询"后刷新图表。

图表展示以下 5 个指标：

| 图表     | 说明 |
|----------|------|
| 在线人数 | 周期内每天/周/月的活跃用户数 |
| 在线会话 | 周期内每天/周/月的活跃会话数 |
| 新增人数 | 周期内首次使用的新用户数 |
| 新建会话 | 周期内每天/周/月的新建会话数 |
| 消息数量 | 周期内每天/周/月的消息发送数 |

每个图表标题右侧显示该周期内的统计数据：`总数 X · 最大 Y · 平均 Z`，随时间范围切换自动更新。

#### 图表筛选

- 点击"图表筛选 ▾"下拉按钮可展开勾选列表
- 勾选/取消勾选可显示/隐藏对应图表
- 默认全部显示
- 图表显示/隐藏状态保存在浏览器本地，刷新后保留

### 刷新方式

- **手动刷新**：右上角"手动刷新"按钮
- **自动刷新**：每 30 秒自动刷新一次

## 系统监控

### 访问方式

在管理面板中点击"系统监控"标签页。

### 进程监控

监控前端和后端两个进程的运行状态：

| 指标 | 说明 |
|------|---------|
| CPU 占用率 | 1 秒采样内进程 utime+stime 增量折算的 CPU 占用百分比 |
| 内存占用 | 进程 RSS（常驻内存集）大小及占系统总内存的百分比 |
| 线程数 | 进程当前线程数 |
| 运行时间 | 进程从启动到现在的持续时间 |
| 读 IO 速率 | 1 秒采样内进程 read_bytes 增量，单位 KB/s |
| 写 IO 速率 | 1 秒采样内进程 write_bytes 增量，单位 KB/s |

- **后端进程**：通过 `pgrep -f "opencode serve.*--port <端口>"` 查找
- **前端进程**：通过 `pgrep -f "bun.*packages/app"` 查找
- 进程未找到时显示"未找到进程"
- CPU 和内存占用率超过 50% 显示黄色，超过 80% 显示红色

### 系统资源

| 指标 | 说明 |
|------|---------|
| CPU 使用率 | 1 秒采样内 /proc/stat 的 idle 与 total 差值计算 |
| 内存使用率 | 总内存减去可用内存（MemAvailable），单位 MB |
| 系统负载 | /proc/loadavg 的 1 分钟 / 5 分钟 / 15 分钟平均负载 |

- CPU 和内存使用率超过 50% 显示黄色，超过 80% 显示红色

### 磁盘使用

显示系统设置中配置的所有挂载点的磁盘使用情况：

| 指标 | 说明 |
|------|---------|
| 挂载点 | 磁盘挂载路径 |
| 总容量 | 磁盘总大小 |
| 已用 / 可用 | 已使用和剩余空间 |
| 使用率 | 已用空间占总容量的百分比 |

- 使用率超过 70% 显示黄色，超过 90% 显示红色

### 磁盘 IO

显示各块设备的读写性能指标：

| 指标 | 说明                                                          |
|------|---------------------------------------------------------------|
| 读速率 | 1 秒采样内 /proc/diskstats 扇区读增量 × 512 / 1024，单位 KB/s |
| 写速率 | 1 秒采样内 /proc/diskstats 扇区写增量 × 512 / 1024，单位 KB/s |
| 读等待 | 1 秒采样内读耗时增量除以读完成数，单位毫秒                    |
| 写等待 | 1 秒采样内写耗时增量除以写完成数，单位毫秒                    |
| 读利用率 | 1 秒采样内读耗时占采样时间的百分比                            |
| 写利用率 | 1 秒采样内写耗时占采样时间的百分比                            |

- tmpfs 等虚拟文件系统无 IO 统计，显示 `-`
- 等待时间超过 20ms 显示黄色，超过 50ms 显示红色
- 利用率超过 50% 显示黄色，超过 80% 显示红色

### 刷新方式

- **手动刷新**：右上角"手动刷新"按钮
- **自动刷新**：每 30 秒自动刷新一次
- 切换到其他标签页时自动停止刷新

## 系统配置

### 访问方式

在管理面板中点击"系统设置"标签页。

### 配置项说明

配置分为两组：

#### 功能参数

| 配置项 | .env 变量名 | 说明 |
|--------|------------|------|
| 公告 | `VITE_ANNOUNCEMENT_TEXT` | 顶部公告条显示的内容，为空则不显示 |
| 支撑人员 | `VITE_CONTACT_ADMIN` | 联系方式列表，多个用 `\|` 分隔 |
| 意见反馈 URL | `VITE_FEEDBACK_URL` | 点击后新窗口打开的反馈页面地址 |
| 帮助文档 URL | `VITE_HELP_DOC_URL` | 点击后新窗口打开的帮助文档地址 |
| 知识库目录 | `VITE_CASE_LIBRARY_DIR` | 本地案例库文件所在目录路径 |
| 隐藏供应商 | `VITE_HIDDEN_PROVIDERS` | 隐藏的供应商 ID，逗号分隔，隐藏后用户模型选择器和管理面板均不显示 |

#### 系统参数

| 配置项 | .env 变量名 | 说明 |
|--------|------------|------|
| 文件树监听周期（毫秒） | `VITE_FILE_TREE_POLL_INTERVAL` | 文件树自动刷新间隔，默认 5000 毫秒 |
| 心跳周期（毫秒） | `VITE_HEARTBEAT_INTERVAL` | 客户端心跳上报间隔，默认 60000 毫秒 |
| 磁盘使用率阈值（%） | `VITE_DISK_USAGE_THRESHOLD` | 超过此阈值时禁止上传文件，默认 90% |
| 监控磁盘挂载点 | `VITE_MONITOR_DISK_MOUNTS` | 系统监控页面展示的磁盘挂载点，逗号分隔，默认 `/` |
| 后端进程匹配规则 | `VITE_MONITOR_BACKEND_PATTERN` | 系统监控中匹配后端进程的 pgrep 模式，为空时默认 `opencode serve.*--port 端口` |
| 前端进程匹配规则 | `VITE_MONITOR_FRONTEND_PATTERN` | 系统监控中匹配前端进程的 pgrep 模式，为空时默认 `bun.*packages/app` |
| 允许自助注册 | `VITE_REGISTRATION_ENABLED` | 是否开放用户注册页面，`true`=开放，`false`=关闭（默认）。仅在 `AUTH_ENABLED=true` 时显示此配置项 |
| 模型检测超时（毫秒） | `VITE_MODEL_TEST_TIMEOUT` | 单个模型检测的超时时间，默认 30000 毫秒（30秒） |

### 注意事项

- 点击"保存配置"后，配置同时写入内存和 `.env` 文件，页面提示"配置已保存，刷新页面生效，重启后持久化"
- 修改配置后建议刷新前端页面确保生效
- 支撑人员多个联系方式用 `|` 分隔
- 公告文案支持多行文本

## 模型管理

### 访问方式

在管理面板中点击"模型管理"标签页。

### 模型列表

显示所有已配置供应商的模型，表格包含以下列：

| 列 | 说明 |
|------|------|
| 供应商 | 供应商名称 |
| 模型 | 模型名称 |
| 状态 | 模型状态：active（绿色）/ beta（黄色）/ alpha（灰色） |
| 检测结果 | ✓ 可用（绿色）/ ✗ 错误信息（红色），未检测时显示 `-` |
| 耗时 | 检测耗时，超过 10 秒显示红色，超过 5 秒显示黄色 |
| 检测时间 | 最近一次检测的时间 |
| 操作 | 「检测」按钮 |

已隐藏的供应商（在系统设置中配置）不显示。检测结果存入数据库，刷新页面或重新进入后仍可查看历史检测数据。

### 单个检测

点击每行的"检测"按钮，系统会创建临时会话并向该模型发送测试消息，检测完成后显示结果和耗时，并存入数据库。

### 检测全部

点击顶部"检测全部"按钮，依次检测所有模型，检测过程中显示进度（如 `正在检测 3/10`）。

### 隐藏供应商

在系统设置的「系统参数」中配置「隐藏供应商」字段，输入要隐藏的供应商 ID（逗号分隔）。隐藏后：

- 模型管理 Tab 不显示该供应商的模型
- 用户端模型选择器不显示该供应商的模型

## 用户管理

### 访问方式

在管理面板中点击"用户管理"标签页。仅超级管理员可见此标签页。

### 用户列表

显示所有用户（含管理员创建和自助注册），包括用户名、角色、创建时间和操作按钮。

### 新增用户

点击右上角"+ 新增用户"按钮，在弹出的对话框中填写：

| 字段 | 说明 |
|------|------|
| 用户名 | 登录用户名，不可重复 |
| 密码 | 至少 8 位，需包含数字/大写字母/小写字母/特殊字符中的 3 种 |
| 角色 | 可选「普通用户」或「管理员」 |

### 编辑用户

点击用户列表中的"修改"按钮，可修改密码和角色：

- 密码留空表示不修改
- 用户名不可修改
- 超级管理员账户不可编辑

### 删除用户

点击用户列表中的"删除"按钮，确认后删除：

- 超级管理员账户不可删除
- 不可删除自己
