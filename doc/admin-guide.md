# 运维指南

本文档面向管理员，介绍统计面板和系统配置的使用方法。

## 统计面板

### 访问方式

在浏览器中访问：

```
http://<WEB_HOST>:<WEB_PORT>/admin.html?token=<VITE_STATS_ADMIN_TOKEN>
```

- `WEB_HOST`：前端监听地址（`.env` 中 `WEB_HOST`）
- `WEB_PORT`：前端端口（`.env` 中 `WEB_PORT`，默认 3000）
- `VITE_STATS_ADMIN_TOKEN`：管理面板访问令牌（`.env` 中配置）

### 概览数据

统计面板顶部显示以下概览信息：

| 指标           | 说明 |
|----------------|------|
| 总人数         | 累计使用过的不同用户数 |
| 在线人数       | 最近 10 分钟内有活跃的用户数 |
| 总会话         | 历史创建的会话总数 |
| 在线会话       | 最近 10 分钟内有活跃的会话数 |
| 正在处理问题数 | AI 正在处理的会话数 |
| 总消息数       | 用户发送的消息总数 |

### 在线会话表格

显示当前在线的会话列表：

| 字段 | 说明 |
|------|------|
| 会话 ID | Session 唯一标识 |
| 客户端 IP | 客户端 IP 地址（`.` 替换为 `_`） |
| 最后心跳时间 | 最后一次心跳的时间 |
| 状态 | AI处理中 / 重试中 / 空闲 |
| 操作 | 点击"跳转"在新窗口打开对应会话 |

- **状态排序**：AI处理中 > 重试中 > 空闲
- **状态筛选**：全部 / AI处理中 / 重试中 / 空闲
- **IP 筛选**：可按客户端 IP 筛选
- **搜索**：支持按会话 ID、客户端 IP、心跳时间搜索
- **分页**：每页 10 条

### 使用趋势

显示使用趋势图表，支持 4 种时间范围切换：

| 按钮 | 时间范围 | 聚合粒度 |
|------|---------|---------|
| 近7天 | 7 天 | 按天 |
| 近1月 | 30 天 | 按天 |
| 近1季 | 90 天 | 按周 |
| 近1年 | 365 天 | 按月 |

图表展示以下 5 个指标：

| 图表     | 说明 |
|----------|------|
| 在线人数 | 周期内每天/周/月的活跃用户数 |
| 在线会话 | 周期内每天/周/月的活跃会话数 |
| 新增人数 | 周期内首次使用的新用户数 |
| 新建会话 | 周期内每天/周/月的新建会话数 |
| 消息数量 | 周期内每天/周/月的消息发送数 |

每个图表标题右侧显示该周期内的统计数据：`总数 X · 最大 Y · 平均 Z`，随时间范围切换自动更新。

#### 图表筛选

- 点击"图表筛选 ▾"下拉按钮可展开勾选列表
- 勾选/取消勾选可显示/隐藏对应图表
- 默认全部显示
- 图表显示/隐藏状态保存在浏览器本地，刷新后保留

### 刷新方式

- **手动刷新**：右上角"手动刷新"按钮
- **自动刷新**：每 30 秒自动刷新一次

## 系统监控

### 访问方式

在管理面板中点击"系统监控"标签页。

### 进程监控

监控前端和后端两个进程的运行状态：

| 指标 | 说明 |
|------|---------|
| CPU 占用率 | 1 秒采样内进程 utime+stime 增量折算的 CPU 占用百分比 |
| 内存占用 | 进程 RSS（常驻内存集）大小及占系统总内存的百分比 |
| 线程数 | 进程当前线程数 |
| 运行时间 | 进程从启动到现在的持续时间 |
| 读 IO 速率 | 1 秒采样内进程 read_bytes 增量，单位 KB/s |
| 写 IO 速率 | 1 秒采样内进程 write_bytes 增量，单位 KB/s |

- **后端进程**：通过 `pgrep -f "opencode serve.*--port <端口>"` 查找
- **前端进程**：通过 `pgrep -f "bun.*packages/app"` 查找
- 进程未找到时显示"未找到进程"
- CPU 和内存占用率超过 50% 显示黄色，超过 80% 显示红色

### 系统资源

| 指标 | 说明 |
|------|---------|
| CPU 使用率 | 1 秒采样内 /proc/stat 的 idle 与 total 差值计算 |
| 内存使用率 | 总内存减去可用内存（MemAvailable），单位 MB |
| 系统负载 | /proc/loadavg 的 1 分钟 / 5 分钟 / 15 分钟平均负载 |

- CPU 和内存使用率超过 50% 显示黄色，超过 80% 显示红色

### 磁盘使用

显示系统设置中配置的所有挂载点的磁盘使用情况：

| 指标 | 说明 |
|------|---------|
| 挂载点 | 磁盘挂载路径 |
| 总容量 | 磁盘总大小 |
| 已用 / 可用 | 已使用和剩余空间 |
| 使用率 | 已用空间占总容量的百分比 |

- 使用率超过 70% 显示黄色，超过 90% 显示红色

### 磁盘 IO

显示各块设备的读写性能指标：

| 指标 | 说明                                                          |
|------|---------------------------------------------------------------|
| 读速率 | 1 秒采样内 /proc/diskstats 扇区读增量 × 512 / 1024，单位 KB/s |
| 写速率 | 1 秒采样内 /proc/diskstats 扇区写增量 × 512 / 1024，单位 KB/s |
| 读等待 | 1 秒采样内读耗时增量除以读完成数，单位毫秒                    |
| 写等待 | 1 秒采样内写耗时增量除以写完成数，单位毫秒                    |
| 读利用率 | 1 秒采样内读耗时占采样时间的百分比                            |
| 写利用率 | 1 秒采样内写耗时占采样时间的百分比                            |

- tmpfs 等虚拟文件系统无 IO 统计，显示 `-`
- 等待时间超过 20ms 显示黄色，超过 50ms 显示红色
- 利用率超过 50% 显示黄色，超过 80% 显示红色

### 刷新方式

- **手动刷新**：右上角"手动刷新"按钮
- **自动刷新**：每 30 秒自动刷新一次
- 切换到其他标签页时自动停止刷新

## 系统配置

### 访问方式

在管理面板中点击"系统设置"标签页。

### 配置项说明

| 配置项 | .env 变量名 | 说明 |
|--------|------------|------|
| 公告 | `VITE_ANNOUNCEMENT_TEXT` | 顶部公告条显示的内容，为空则不显示 |
| 支撑人员 | `VITE_CONTACT_ADMIN` | 联系方式列表，多个用 `\|` 分隔 |
| 意见反馈 URL | `VITE_FEEDBACK_URL` | 点击后新窗口打开的反馈页面地址 |
| 帮助文档 URL | `VITE_HELP_DOC_URL` | 点击后新窗口打开的帮助文档地址 |
| 知识库目录 | `VITE_CASE_LIBRARY_DIR` | 本地案例库文件所在目录路径 |
| 下载截断标记 | `VITE_DOWNLOAD_CUTOFF_TEXT` | 下载回复时从包含此文本的行起截断，为空表示不截断 |
| 文件树监听周期（毫秒） | `VITE_FILE_TREE_POLL_INTERVAL` | 文件树自动刷新间隔，默认 5000 毫秒 |
| 心跳周期（毫秒） | `VITE_HEARTBEAT_INTERVAL` | 客户端心跳上报间隔，默认 60000 毫秒 |
| 磁盘使用率阈值（%） | `VITE_DISK_USAGE_THRESHOLD` | 超过此阈值时禁止上传文件，默认 90% |
| 监控磁盘挂载点 | `VITE_MONITOR_DISK_MOUNTS` | 系统监控页面展示的磁盘挂载点，逗号分隔，默认 `/` |

### 注意事项

- 修改配置后建议刷新前端页面确保生效
- 下载截断标记为空时下载完整回复，非空时从包含该标记文本的行起截断
- 支撑人员多个联系方式用 `|` 分隔
- 公告文案支持多行文本
