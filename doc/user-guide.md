# 使用指南

本文档面向终端用户，详细介绍各功能模块的使用方法。

## 新手指引

### 自动弹出

打开自己的项目页面时，系统会自动弹出新手指引（打开他人分享的链接不弹出）。引导期间无法操作背景内容，需完成或跳过后才能操作。

### 引导步骤

| 步骤 | 模块 | 说明 |
|------|------|------|
| 1 | 欢迎页 | 点击"开始引导"进入下一步 |
| 2 | 公告栏 | 顶部黄色公告条，显示系统公告和重要通知 |
| 3 | 会话列表 | 左侧栏显示所有会话，点击可切换 |
| 4 | 输入框 | 底部输入框，输入问题后回车发送给 AI |
| 5 | 文件树 | 右侧面板，上传和管理文件，拖拽文件上传 |
| 6 | 使用说明 | 文件树下方，介绍如何引用文件、删除文件及使用示例 |
| 7 | 帮助文档 | 顶部栏左侧按钮，点击查看详细文档 |
| 8 | 新手指引按钮 | 顶部栏左侧，随时点击可重新查看引导 |
| 9 | 知识库 · 支撑人员 · 问题反馈 | 右侧入口，知识库查阅案例，联系支撑人员，提交问题反馈 |
| 10 | 完成页 | 点击"完成"结束引导 |

### 操作按钮

- **跳过**：直接关闭引导，本次页面加载不再弹出
- **上一步**：返回上一个步骤
- **下一步**：进入下一个步骤
- **开始引导**：从欢迎页进入第一步
- **完成**：结束引导

### 重新查看

点击顶部栏左侧的"新手指引"按钮，随时重新启动引导。

## 公告栏

- **位置**：页面最顶部，黄色背景条
- **内容**：系统公告、排队提示、清理策略等重要通知
- **查看**：打开页面即可看到，无需操作

## 聊天界面

### 会话列表

- 位于页面左侧栏
- 显示当前项目下的所有会话
- 点击会话可切换查看
- 每个会话显示标题和最后活跃时间

### 新建会话

- 点击顶部栏左侧的新建按钮

### 消息发送

- 在页面底部输入框中输入问题
- 按回车键发送给 AI 助手
- AI 处理过程中会话状态显示为"AI处理中"
- AI 重试过程中会话状态显示为"重试中"

### 下载回复

- **入口**：AI 回复消息下方，"复制回复"按钮旁边的下载图标
- **文件格式**：Markdown（.md）
- **文件名规则**：`{会话标题}.md`，文件名中的特殊字符 `\/:*?"<>|` 会被替换为 `_`
- **截断标记**：
  - 如果管理员配置了下载截断标记，从包含该标记文本的行开始，该行及之后内容不下载
  - 如果截断标记为空（未配置），下载完整回复
  - 截断是逐行扫描，匹配到包含标记文本的行即停止，该行本身也不包含在下载内容中

## 文件树

### 位置与展开

- 位于页面右侧面板
- 点击顶部栏右侧的文件树切换按钮可展开/收起

### 文件上传

- 将文件拖拽到文件树区域即可上传
- 上传过程中显示加载动画

### 文件下载

- 右键点击文件 → 选择"下载"

### 文件删除

- 右键点击文件或目录 → 选择"删除文件"
- 删除目录会递归删除目录下所有文件

### 引用文件

- 双击一级目录可在输入框中自动填入文件引用
- 引用格式：`@uploads/ses_xxx/文件名`
- AI 可读取被引用的文件内容进行分析

### 使用说明区域

- 位于文件树下方
- 包含以下内容：
  - **使用场景**：分析 plog 日志、dump 图（txt 格式）和 profiling 等
  - **引用文件**：双击一级目录引用文件或目录，输入框自动填入
  - **删除文件**：右键选择"删除文件"
  - **使用示例**：完整的使用示例说明

## 知识库

### 入口

- 页面右侧"知识库"按钮（橙色）

### 功能

- 浏览本地案例库文件
- 点击文件可查看内容
- 支持文件链接跳转

### 前进/后退导航

- 文件路径旁有前进（→）和后退（←）按钮
- 点击文件链接后自动加入历史记录
- 可通过前进/后退按钮在历史记录中切换
- 点击新文件时会截断前进历史

## 帮助文档

### 入口

- 顶部栏左侧"帮助文档"按钮

### 使用

- 点击后在新窗口打开帮助文档页面

## 问题反馈

### 入口

- 页面右侧"问题反馈"按钮（绿色）

### 使用

- 点击后在新窗口打开问题反馈页面
- 在反馈页面中填写并提交问题

## 支撑人员联系

### 入口

- 页面右侧"支撑人员"按钮（蓝色）

### 使用

- 鼠标悬停在按钮上会弹出联系方式列表
- 列表中显示所有支撑人员的联系方式
- 点击联系方式可复制到剪贴板

## 权限说明

### 项目隔离

- 系统根据客户端 IP 自动创建专属项目目录（`默认目录/客户端IP`）
- 每个用户只能在自己的项目目录下操作
- 打开他人分享的会话链接时，以只读方式查看，不影响统计数据

### 权限限制

| 场景 | 自己的项目 | 他人的项目 |
|------|----------|--------|
| 新建会话 | ✅ | ❌ |
| 发送消息 | ✅ | ❌ |
| 文件上传 | ✅ | ❌ |
| 文件删除 | ✅ | ❌ |
| 新手指引 | ✅ | ❌ |
| 心跳上报 | ✅ | ❌ |
| 查看会话 | ✅ | ✅ |
